F1ピットウォールから学ぶ「データの力」

🏁 ピットウォールのエンジニアはなぜ速いのか
F1チームのピットウォールを想像してほしい。レースエンジニアたちは、毎戦ただスタートを切るだけじゃない。過去の全レースデータ・今日の気温・路面温度・タイヤのデグラデーション・ライバルの戦略傾向——そのすべてを前のレースから積み上げ続けて、今日の1戦に臨んでいる。

「前回のモナコでは第2スティントのタイヤ選択が裏目に出た。今日の気温はあのときより8度高い。ならソフトは捨てて、ミディアムからスタートすべきだ」

この「判断の速さ」は才能じゃない。データが積み上がっているからだ。
⚠️
ほとんどの人のAIの使い方 ChatGPTやClaudeを開くたびに自己紹介から始めて、昨日3時間かけて調べた内容を今日もゼロから説明し直す。毎レース、テレメトリーデータを全消去してスタートしているようなものだ。
💡
海外のAI活用コンサル Adam Sandler氏はこれを「ほとんどの人はAIを記憶喪失の派遣社員のように使っている」と表現した。これはAIの性能不足じゃない。「記憶の設計」をしていないせいだ。
😩

仕組みはシンプルな3層構造

📥
raw/ フォルダ
記事・PDF・メモを何でも放り込む場所。AIは読むだけ。絶対に書き換えない。
📖
wiki/ フォルダ
AIが要約・概念ページを自動生成。新情報が来るたびに自動更新される。
⚙️
CLAUDE.md
AIへの指示書。「こう運用して」というルールを一度書けば毎回自動で読み込まれる。
🚀

今夜30分で土台を作る5ステップ

1
📱 Obsidianをインストール
⏱ 約5分
obsidian.md にアクセスして無料でダウンロード。起動したら「Create new vault」を選び、好きな名前（「副業ナレッジ」「My Brain」何でもOK）でフォルダを作成。
💬
保存場所はデスクトップでもドキュメントでも大丈夫。後から変えられます。
2
📁 3つのフォルダを作る
⏱ 約3分
「raw」「wiki」「outputs」の3つだけ作ればOK。完璧な分類を考え込まないで。分類は後でAIに任せます。
⚠️
「完璧なフォルダ構造」を考え始めた瞬間に時間が溶けます。3フォルダで即スタートが鉄則。
3
💻 Claude Codeをインストール
⏱ 約10分
① Node.js を公式サイトからインストール（LTS版を選ぶだけ）
② ターミナルを開いて以下をコピペ： npm install -g @anthropic-ai/claude-code ③ Vaultフォルダに移動して claude と打つだけ。
💬
ターミナル未経験でも全く問題なし！Claudeに「Claude Codeのインストール方法を1行ずつ教えて」と聞けば手取り足取り解説してくれます。

💳 Claude Proプラン（月$20）が必要ですが、最初の1ヶ月で確実に回収できます。
4
📝 設計図を2枚書く
⏱ 約7分
Vaultのトップに「CLAUDE.md」と「Memory.md」の2ファイルを作成。CLAUDE.mdにはAIへのルールを書きます： - /raw/ → 元素材。読み取り専用。書き換えない
- /wiki/ → AIが管理する知識ベース
- 新しい素材を処理したら要約をwiki/に作り
　関連する既存ページも更新する
- 質問にはwikiの内容を引用しながら答える
✏️
Memory.mdには「仕事の内容・副業の目標・興味分野」を書こう。Claudeと20分雑談してその内容をコピペするだけでも十分機能します。
5
🎉 最初の記事を放り込んでみる
⏱ 約5分
「最近読んで良かった」記事を1本、raw/フォルダに保存。ファイル名は何でもOK。そしてこう打つだけ： raw/に新しい記事を入れたから、
要約をwiki/に作って、
関連する概念ページも作って
🌟
これだけで記事1本から8〜15ページ分のWikiが自動生成されます！Obsidianのグラフビュー（Ctrl+G）を開くと、ノードが線でつながっていく様子が見えます。
🔄

日常で回す3つの操作だけ

📥
① Ingest（取り込み）
記事・メモをraw/に放り込んで「処理して」と頼むだけ。8〜15ページのWikiが自動生成される。
💬
② Query（質問）
「あの件でどんな情報があった？」と聞くだけ。過去の情報を引用付きで即答してくれる。
🔍
③ Lint（健康チェック）
月1回「矛盾・古い情報を見つけて」と頼むだけ。AIが数分でスキャンして修正案を出す。
⭐
最初は「Ingest」だけでOK！ 週2〜3本放り込む習慣だけつければ、1ヶ月後には10〜15本分の構造化された知識が手元に残ります。「全部一気にやろう」と思った瞬間、Notion挫折と同じ道が始まります。
⏰

💰 副業ネタが「複利」で資産化する
F1エンジニアが毎戦データを積み上げるように、読んだ記事・聞いたポッドキャストをraw/に入れ続けるだけでネタ帳が勝手に育つ。「副業のターゲット向けに、過去の情報から訴求軸を3つ提案して」と聞くだけで、蓄積をフルに使った提案がゼロ秒で出てくる。
✏️ コンテンツ制作の「白紙の恐怖」がなくなる
「Memory.mdの自分のキャラと、過去の記事をベースにX投稿の構成案を5本出して」で、自分らしい切り口が即座に揃う。書き始めるまでの摩擦がほぼゼロになります。
✅

挫折しないための5つのチェック

  • 🚫
    完璧なフォルダ構造を設計しない — 3フォルダで始める。考え込んだ瞬間に負け。
  • 📄
    最初の3ページは質が低くていい — 「本物の情報」であることだけが大事。
  • 🔌
    プラグインを増やしすぎない — 標準機能 + Web Clipperで十分。沼にハマらない。
  • 👤
    Memory.mdに自分の情報を書く — ここを書くか書かないかで、AIの回答精度が劇的に変わる。最重要。
  • 🌐
    Ingest後にグラフビューを開く — 知識が育つのが視覚化されると、続けたくなる。モチベの源泉。
📅
